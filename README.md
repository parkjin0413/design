# 강산인테리어 — 인테리어 스튜디오 랜딩 페이지

taste-skill(leonxlnx/taste-skill)의 디자인 원칙을 적용해 만든 모던 럭셔리 인테리어
스튜디오 랜딩 페이지 정적 프로토타입입니다. 그누보드5 테마로 이식하는 것을 전제로
React/빌드 도구 없이 순수 HTML + CSS + Vanilla JS(+GSAP CDN)로 작성했습니다.

## 미리보기

```bash
npx serve .
# 또는
python -m http.server 5173
```

## 디자인 방향

- **디자인 리드**: 안목 있는 하이엔드 주거 고객 대상, 갤러리형 에디토리얼 언어의
  프리미엄 컨슈머 랜딩 페이지.
- **다이얼**: DESIGN_VARIANCE 7 / MOTION_INTENSITY 6 / VISUAL_DENSITY 3
  (비대칭 벤토 그리드, 절제된 스크롤 모션, 여백이 넉넉한 갤러리형 밀도)
- **팔레트**: 오프화이트(`#f2f0ea`) + 잉크블랙(`#16171a`) 뉴트럴 + 단일 포인트 컬러
  딥 파인그린(`#1f3d2f`). 흔한 "베이지 + 브라스 + 에스프레소" 인테리어 사이트
  클리셰를 피하고, 실제 시공 사진(우드/마블 톤)이 색감을 주도하도록 설계했습니다.
- **타이포그래피**: Pretendard Variable 하나로 통일(한글 가독성 우선, 세리프 미사용).
- **셰이프 규칙**: 카드/이미지/인풋/버튼 등 사각 요소는 각(0), 버튼만 필(pill) 형태.

## 그누보드5 테마 이식 가이드

이 프로토타입은 그누보드5의 반응형 테마(스킨) 구조로 옮기는 것을 염두에 두고
섹션을 나눠 작성했습니다. `index.html`에 있는 한글 주석을 따라가면 됩니다.

| 이 파일의 영역 | 이식 위치(그누보드5 테마 관례) |
|---|---|
| `<header class="nav">` ~ `<div class="mobile-menu">` | 테마 공통 헤더(`head.sub.php` 등 상단 공통 include) |
| `.nav__menu`, `.mobile-menu__menu` 내부 `<ul><li><a>` | 그누보드5 관리자 메뉴 관리 기능으로 대체할 지점. `index.html`의 해당 위치에 상세 주석을 남겨뒀습니다 |
| `<main id="main">` 내부 각 `<section>` | 테마의 메인 페이지 템플릿(예: `index.php`) 본문. 섹션 단위로 그대로 옮기면 됩니다 |
| `<footer class="footer">` | 테마 공통 푸터(`tail.sub.php` 등 하단 공통 include) |
| `assets/css/style.css` | 테마 `css/` 폴더로 이동. `:root` 토큰과 공통 클래스는 `common.css` 등으로, 필요 시 페이지별로 분리 |
| `assets/js/main.js` | 테마 `js/` 폴더로 이동, 공통 include에서 `defer`로 로드 |

### 상담 신청 폼 연동

`#contact` 섹션의 `<form>`은 필드명을 그누보드 게시판 글쓰기 파라미터에 맞춰
`wr_name`, `wr_1`(연락처), `wr_2`(공간 유형), `wr_content`로 미리 맞춰뒀습니다.

- 문의 전용 게시판(`bo_table`)을 하나 만들고 `form action`을
  `/bbs/board_write_update.php` 또는 별도로 만든 처리 스크립트로 지정하면
  기존 그누보드 글쓰기 로직을 그대로 활용할 수 있습니다.
- 스팸 방지를 위해 캡차(`bo_use_captcha`) 또는 별도 처리 스크립트에서
  honeypot 필드를 추가하는 것을 권장합니다.
- 개인정보 수집 동의 체크박스(`form-consent`)는 실제 약관 페이지로 링크를
  연결해 주세요.

### 유지해야 할 것

- CSS 변수(`:root` 토큰), 셰이프/컬러 락 규칙은 다른 페이지(프로젝트 상세,
  소개 페이지 등)를 추가로 만들 때도 그대로 재사용하면 디자인 일관성이 유지됩니다.
- `.reveal` + `html.has-js` 조합은 JS가 어떤 이유로든 로드되지 않아도 콘텐츠가
  항상 보이도록 하는 안전장치입니다. 그누보드 테마에 다른 스크립트를 추가로 붙일
  때도 이 구조를 깨지 않도록 주의해 주세요.

## 접근성 / 성능 메모

- `prefers-reduced-motion`을 존중합니다(리빌 애니메이션, 디테일 갤러리 가로 스크롤 핀 모두).
- 디테일 갤러리는 데스크톱에서 GSAP ScrollTrigger로 가로 스크롤 핀 연출을 사용하고,
  모바일/모션 축소 환경에서는 가로 스크롤 스냅 리스트로 자동 대체됩니다.
- 네비게이션 배경 전환은 `scroll` 이벤트 대신 `IntersectionObserver`로 처리해
  스크롤 성능에 영향이 없습니다.
